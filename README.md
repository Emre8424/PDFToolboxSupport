# PDF Toolbox by EDS

A free native iOS document scanner and local PDF utility for iPhone and iPad. Documents are processed on your device. No account or subscription.

Support and privacy questions: [info@eds-solutions.co](mailto:info@eds-solutions.co).

Read the [privacy policy](PRIVACY.md).

PDF Toolbox can scan and organize pages, create PDFs from selected images, merge/split/extract pages, rotate pages, add a visual handwritten signature, add text, protect a copy with a password, and recognize text locally using Apple Vision.

Compression creates image-based PDF copies only when smaller; it removes searchable text, links and editable annotations from that copy. OCR accuracy varies. Handwritten signatures are visual marks, not certified digital signatures. Export important documents before deleting the app: app files are excluded from automatic backups.

A small non-personalized AdMob banner in the file browser funds the app. Ad services use network/device/interaction data; document content is never sent to them.
